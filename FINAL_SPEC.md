# VectorMeter Final Specification

Brand: VectorMeter
Theme: black / red / silver / white

Menu 1: RealVector
- Start/Stop
- GPS realtime
- live KM
- start/finish timestamps
- route trace

Menu 2: VectorPlan
- no start/stop
- multi-stop route
- stop selection by tapping map
- OSRM/OpenStreetMap route distance
- 5 columns:
  NOMOR | TUJUAN | KM AWAL | KM AKHIR | JUMLAH (KM)
- KM AWAL manual
- KM AKHIR = KM AWAL + JUMLAH
- TOTAL below the table
